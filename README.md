# Weather Haiku

A simple weather-based website that generates a haiku depending on the current weather in your location.

Sunny weather gives cheerful poems, rainy weather gives calm or emotional ones, and every refresh creates a different result.

---

## Features

- Detects current weather using a free API
- Generates different haikus for different weather conditions
- Changes background based on weather
- Responsive design
- Built using only HTML, CSS, and JavaScript

---

## Built With

- HTML
- CSS
- JavaScript
- Open-Meteo API

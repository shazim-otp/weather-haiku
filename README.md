# weather-haiku

A website that generates a unique haiku every time you load it, based on the current weather in your city using a free API — like sunny days = lighthearted haikus, rain = melancholy ones.

Why this fits you: You've built HTML/CSS/JS websites and played with AI text generation — this merges real-world data (weather) with poetic output, stretching your skills into API consumption and dynamic content.
